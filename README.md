# 邱雅婧个人网站

线上访问：[JANICE Portfolio](https://onyourjanice-star.github.io/janice-portfolio/) · [自动部署记录](https://github.com/onyourjanice-star/janice-portfolio/actions)

部署与后续更新说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。

参考 mingmingzi.com 的暖白与森林绿风格、横向案例列表、首屏双入口和详情页阅读方式，独立实现为无构建依赖的静态网站。

## 本地运行

在此目录运行 `node server.cjs`，访问 http://127.0.0.1:4173 。运行 `node check.cjs` 可检查项目、素材与来源完整性。

网站入口为 `dist/index.html`。`dist/content.js` 保存可编辑文案、数据口径与素材引用；`dist/styles.css` 为样式；`dist/app.js` 为交互。部署时只使用 `dist/`，不要上传工作区的原始文档、研究提取文件或参考站点源码。
